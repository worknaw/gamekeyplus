# Ldiwaa-Shop (GameKeyPlus) 🎮

ระบบร้านค้าออนไลน์สำหรับขายคีย์เกม (Game Keys), บัตรเติมเงิน (Gift Cards) และบริการเติมเกมออนไลน์ พัฒนาด้วยภาษา **PHP (PDO)** และฐานข้อมูล **MySQL** โดยไม่มีการใช้ framework ภายนอก ทำให้ทำงานได้รวดเร็วและติดตั้งได้ง่าย

---

## ✨ คุณสมบัติของระบบ (Features)

### 👤 ส่วนของลูกค้า (Customer Frontend)
- **หน้าแรก (Home Page):** แสดงสไลด์แบนเนอร์ (Carousel) รายการข้อเสนอพิเศษ (Specials) สินค้าแบ่งตามหมวดหมู่ และข่าวสารโปรโมชันล่าสุด
- **หน้ารายการสินค้า (Products List):** สามารถค้นหาและกรองสินค้าตามหมวดหมู่ที่กำหนดได้
- **หน้ารายละเอียดสินค้า (Product Detail):**
  - เลือกแพ็กเกจ/ราคา/ระดับ (Tier) ที่ต้องการได้
  - ช่องกรอกข้อมูลเพิ่มเติม เช่น Game UID สำหรับบริการเติมเงินเข้าไอดีโดยตรง
  - ปรับแต่งจำนวนสินค้าและกดหยิบใส่ตะกร้า (Add to Cart) หรือสั่งซื้อทันที (Buy Now)
- **ระบบตะกร้าสินค้า (Shopping Cart):** ดูรายการสินค้า ปรับจำนวน ลบสินค้า และคำนวณราคารวมโดยอัตโนมัติ
- **ระบบชำระเงิน (Checkout & Payment Gateway):**
  - เลือกช่องทางการชำระเงินที่ต้องการ (พร้อมเพย์ PromptPay, TrueMoney Wallet)
  - หน้าแสดง QR Code และรายละเอียดการโอนเงิน
  - ระบบแนบหลักฐานการโอนเงิน (Upload Pay Slip) เพื่อให้แอดมินตรวจสอบ
- **ระบบสมาชิก (User Profile & Account):**
  - สมัครสมาชิก (Register) และเข้าสู่ระบบ (Login) ด้วยระบบความปลอดภัยขั้นพื้นฐาน
  - ตรวจสอบประวัติการสั่งซื้อ (Order History) และสถานะการชำระเงิน/การจัดส่ง
  - หน้าแสดงรายละเอียดการสั่งซื้อพร้อมรับรหัสคีย์เกม (Redeem Key) ทันทีหลังได้รับการอนุมัติ

### 👑 ส่วนของผู้ดูแลระบบ (Admin Backend)
- **แดชบอร์ด (Dashboard):** แสดงยอดขายรวม จำนวนคำสั่งซื้อทั้งหมด สัดส่วนสถานะการสั่งซื้อ และรายการสั่งซื้อล่าสุด
- **จัดการสินค้าและหมวดหมู่ (Product & Category Management):**
  - เพิ่ม แก้ไข และเปิด/ปิดการใช้งานสินค้า
  - อัปโหลดรูปภาพสินค้า กำหนดภูมิภาค (Region เช่น Global, TH)
  - จัดการแพ็กเกจราคาสินค้าแต่ละชิ้น
- **จัดการคำสั่งซื้อ (Order Management):**
  - ตรวจสอบรายการคำสั่งซื้อของลูกค้า
  - ดูรูปภาพสลีปโอนเงินที่อัปโหลดเข้ามา
  - อนุมัติการชำระเงิน (Confirm Payment) หรืออัปเดตสถานะคำสั่งซื้อเป็นเสร็จสิ้น
- **จัดการคีย์เกม (Redeem Key Management):**
  - เพิ่มหรือนำเข้ารหัสคีย์เกม (Redeem Keys) สำหรับแต่ละแพ็กเกจสินค้า
  - ระบบตรวจสอบคีย์ว่างและระบบตัดสต็อกคีย์แบบอัตโนมัติ (Idempotent assigned keys) เมื่ออัปเดตออเดอร์เป็นชำระเงินแล้ว
- **จัดการผู้ใช้งาน (User Management):**
  - แสดงรายชื่อผู้สมัครสมาชิกทั้งหมด
  - แก้ไขบทบาท (Role: User / Admin) และสถานะบัญชี (Active, Pending, Banned)

## 🛠️ โครงสร้างฐานข้อมูล (Database Schema)

ระบบประกอบด้วยตารางข้อมูลดังต่อไปนี้:
- **`users`**: ข้อมูลบัญชีผู้ใช้งานและแอดมิน (สิทธิ์การใช้งาน, สถานะบัญชี)
- **`categories`**: หมวดหมู่หลักของสินค้า (เช่น เติมเกม, บัตรเติมเงิน)
- **`products`**: รายการสินค้าหลัก รายละเอียด รูปภาพ และสถานะ
- **`product_prices`**: แพ็กเกจหรือตัวเลือกย่อยของแต่ละสินค้า พร้อมราคาและเปอร์เซ็นต์ส่วนลด
- **`carts`**: ข้อมูลตะกร้าสินค้าของผู้ใช้ (บันทึกลงฐานข้อมูลเพื่อให้ตะกร้าไม่หายเมื่อเปลี่ยนอุปกรณ์)
- **`orders`**: คำสั่งซื้อหลัก (บันทึกยอดรวม วิธีชำระเงิน และสถานะคำสั่งซื้อ)
- **`order_details`**: รายละเอียดสินค้าในแต่ละคำสั่งซื้อ (จำนวน, ราคา, และ UID เกม)
- **`payments`**: รายการชำระเงิน ประวัติการอัปโหลดรูปภาพสลิป และสถานะการตรวจสอบสลิป
- **`redeem_keys`**: รหัสคีย์เกมที่รอการขาย (เก็บสถานะ unused/used)
- **`order_redeems`**: บันทึกการส่งมอบรหัสคีย์เกมให้กับลูกค้าในออเดอร์นั้นๆ
- **`promotions`**: ข่าวสาร โปรโมชัน และแบนเนอร์ประชาสัมพันธ์

## ⚙️ วิธีการติดตั้งและใช้งาน (Installation)

### 📋 สิ่งที่ต้องเตรียม (Prerequisites)
- เว็บเซิร์ฟเวอร์ เช่น **XAMPP**, **WampServer**, หรือ **Laragon** (รองรับ PHP 7.4 ขึ้นไป และ MySQL)
- Git (สำหรับโคลนโค้ด)

### 🚀 ขั้นตอนการติดตั้ง
1. **Clone Project** ไปยังโฟลเดอร์สำหรับรันเว็บ (เช่น `htdocs` ของ XAMPP)
   ```bash
   git clone https://github.com/Lzer0x/Ldiwaa-Shop.git
   ```

2. **สร้างฐานข้อมูล**
   - เปิด phpMyAdmin หรือ Database Client อื่นๆ ของคุณ
   - สร้างฐานข้อมูลใหม่ชื่อ `gamekeyplus` (หรือชื่ออื่นๆ ตามต้องการ)
   - นำเข้าไฟล์ SQL Schema (หากมีให้) หรือสร้างตารางตามโครงสร้างที่อธิบายข้างต้น

3. **ตั้งค่าสิ่งแวดล้อม (Configuration)**
   - คัดลอกไฟล์ `.env.example` แล้วเปลี่ยนชื่อเป็น `.env`
   - แก้ไขข้อมูลการเชื่อมต่อฐานข้อมูลตามความจริง:
     ```env
     DB_HOST=localhost
     DB_USER=root
     DB_PASS=
     DB_NAME=gamekeyplus
     ```

4. **เปิดใช้งานระบบ**
   - เริ่มรัน Apache และ MySQL จาก Control Panel ของเครื่องจำลองเซิร์ฟเวอร์
   - เข้าสู่ระบบผ่านเว็บเบราว์เซอร์ที่: `http://localhost/Ldiwaa-Shop` (หรือตามโฟลเดอร์ที่คุณตั้งไว้)
